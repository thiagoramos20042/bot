# WhatsApp Web | Automação com interface

Interface para carregar uma lista CSV e automatizar interações no WhatsApp Web com Selenium.

**Automação e coleta** · Protótipo Streamlit

[← Portfólio de Thiago Oliveira](https://github.com/thiagoramos20042/thiagoramos20042) · [Catálogo de projetos](https://github.com/thiagoramos20042/thiagoramos20042/blob/main/PROJETOS.md)

## Objetivo

Estudar a integração entre entrada de dados em uma aplicação web e controle de navegador.

## O que você encontra

- Upload e leitura de contatos em CSV.
- Interface de operação com Streamlit.
- Automação do navegador usando Selenium.

## Tecnologias

Python · Streamlit · pandas · Selenium

## Como explorar

Na raiz do repositório, em um ambiente Python separado:

```bash
python -m pip install streamlit pandas selenium
python -m streamlit run whatsapp.py
```

## Contexto do projeto

A execução exige uma sessão autenticada no WhatsApp Web e um navegador compatível com a configuração do script. O projeto é um protótipo dependente da interface do serviço.
